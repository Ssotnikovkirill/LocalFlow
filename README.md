# LocalFlow 1.0.6

LocalFlow — нативное приложение локальной диктовки для Apple Silicon Mac.
Удерживайте правую клавишу Option, говорите и отпустите её: приложение
распознает речь локальной моделью OpenAI Whisper и вставит готовый текст в
активное поле.

Интернет для распознавания не нужен. Аудиозаписи не сохраняются.

Это независимая clean-room реализация сценария локальной диктовки. Проект не
содержит закрытый код Wispr Flow и не связан с компанией Wispr Flow.

## Что находится в репозитории

- полный исходный код LocalFlow 1.0.6;
- необходимые статические библиотеки и заголовки whisper.cpp;
- локальные модели Whisper small Q5, Whisper base и Silero VAD;
- тесты и фиксированный RU/EN проверочный корпус;
- скрипты сборки, упаковки и строгой проверки;
- лицензии и уведомления о сторонних компонентах;
- готовое приложение в архиве
  `Releases/LocalFlow-1.0.6-history-last-five-macOS-arm64.zip`.

Старых версий, пользовательских настроек, истории диктовок, логов, временных
сборок и локальных путей пользователя в репозитории нет.

## Возможности

- глобальная диктовка по удержанию физической Right Option;
- мини-оверлей поверх окон без перехвата фокуса;
- волна микрофона и предварительный живой текст;
- полностью локальное распознавание через whisper.cpp;
- русский, English и автоматическое определение языка;
- Whisper small Q5 по умолчанию и более быстрая модель base;
- вставка через Accessibility с безопасным clipboard fallback;
- отдельная поддержка поля ввода Codex;
- пользовательский словарь;
- точные замены распознанных фраз;
- голосовые сниппеты;
- история пяти последних транскрипций с датой и временем;
- запуск при входе в macOS;
- защита password/secure fields;
- отсутствие сетевых API и сохранённых аудиофайлов.

## Требования

- Mac с Apple Silicon: M1 или новее;
- macOS 13.3 или новее;
- около 450 МБ для установленного приложения;
- разрешения Microphone, Accessibility и Input Monitoring;
- Xcode Command Line Tools для сборки из исходников.

Проект разработан и проверен на MacBook Pro M1 2020 с 8 ГБ памяти.

## Простая установка готового приложения

1. Откройте папку `Releases`.
2. Распакуйте `LocalFlow-1.0.6-history-last-five-macOS-arm64.zip`.
3. Переместите `LocalFlow.app` в `/Applications`.
4. Откройте приложение. Если macOS покажет предупреждение, нажмите по
   приложению правой кнопкой → `Открыть` → `Открыть`.
5. В меню LocalFlow выберите `Запросить разрешения…` и выдайте необходимые
   разрешения.
6. Дождитесь статуса `Готов`.

Приложение подписано локальной ad-hoc подписью, а не Apple Developer ID, и не
notarized. Для личного использования это рабочая сборка. Для публичного
распространения потребуется собственная Developer ID подпись и notarization.

## Как пользоваться

1. Поставьте курсор в обычное поле ввода.
2. Нажмите и удерживайте правую Option.
3. Говорите.
4. Отпустите Option.
5. После финального распознавания текст будет вставлен в сохранённое поле.

Не переключайте приложение или поле во время диктовки. В защищённых полях
паролей диктовка намеренно не выполняется.

## Настройки

- `Основное` — язык, модель, живой текст, история и запуск при входе.
- `Словарь` — по одному имени или термину на строку.
- `Замены` — строки вида `что услышано => что вставить`.
- `Сниппеты` — голосовой триггер и готовый текст в том же формате.
- `История` — пять последних финальных текстов с датой и временем.

В истории новая запись находится сверху. Шестая запись автоматически удаляет
самую старую. Можно скопировать выбранную строку, обновить список или очистить
историю после подтверждения. Отключение истории останавливает новые записи,
но не удаляет уже сохранённые.

## Сборка из исходников

Откройте Terminal в корне репозитория и выполните:

```sh
./scripts/build.sh
./scripts/verify.sh
```

Готовый executable появится внутри уникального каталога `.build`.

Для создания нового архива приложения используйте только новое имя и новый
release ID — скрипты специально не перезаписывают существующие результаты:

```sh
LOCALFLOW_RELEASE_ID=my-unique-release \
./scripts/release-gate.sh /absolute/path/LocalFlow-new.zip
```

Полная схема сборки и проверок описана в
[`docs/BUILD-AND-TEST.md`](docs/BUILD-AND-TEST.md).

## Как загрузить эту папку в GitHub

Архив приложения и две модели больше 100 МБ, поэтому они настроены через
Git LFS в файле `.gitattributes`. Не загружайте проект простым перетаскиванием
в браузер GitHub.

Папка уже является чистым Git-репозиторием с веткой `main`, одним начальным
commit и настроенным Git LFS. На этом Mac Git LFS уже установлен. Для проверки:

```sh
git lfs version
git lfs ls-files
git status
```

1. Создайте на GitHub пустой репозиторий без автоматически добавленного README
   или LICENSE.

2. В Terminal перейдите в эту папку, подключите новый репозиторий и отправьте
   файлы, заменив адрес на свой:

```sh
git remote add origin https://github.com/USER/REPOSITORY.git
git push -u origin main
```

3. После загрузки ещё раз проверьте LFS:

```sh
git lfs ls-files
```

Перед публикацией публичного репозитория проверьте доступный объём Git LFS в
своём тарифе GitHub.

## Структура

```text
Sources/       исходный код приложения, Core и C/C++ bridge
Tests/         Swift unit tests
Resources/     Info.plist, entitlements, модели и лицензии
Vendor/        необходимые статические библиотеки whisper.cpp
Validation/    фиксированный тестовый корпус и benchmark tools
scripts/       сборка, упаковка и release gate
Releases/      готовый архив LocalFlow 1.0.6 и SHA-256
docs/          архитектура, приватность и проверка
```

## Приватность и безопасность

- Распознавание работает локально.
- Аудио находится только в оперативной памяти и обнуляется после завершения.
- В историю попадает только финальный текст и максимум пять записей.
- Сеть и облачные API для диктовки не используются.
- Password fields и Secure Event Input защищены намеренным отказом.

Подробнее: [`docs/PRIVACY.md`](docs/PRIVACY.md).

## Лицензирование

Для оригинального кода LocalFlow действует файл [`LICENSE.md`](LICENSE.md).
Лицензии OpenAI Whisper, whisper.cpp и уведомления о сторонних компонентах
находятся в `Resources`.

Текущая лицензия сохраняет все права. Если владелец решит открыть исходный
код для стороннего использования, перед публичной публикацией её нужно
осознанно заменить на выбранную open-source лицензию.
