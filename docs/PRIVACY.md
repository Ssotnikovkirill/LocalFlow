# Приватность и безопасность

## Что обрабатывается

LocalFlow получает аудио с микрофона только во время удержания Right Option.
Аудио преобразуется в 16 kHz mono PCM в оперативной памяти и передаётся
локальным Silero VAD и whisper.cpp.

## Что сохраняется

- Аудио никогда не записывается в файл.
- При включённой истории сохраняются только пять последних финальных текстов,
  дата/время, выбранный язык и модель.
- Словарь, замены, сниппеты и настройки хранятся локально в macOS Preferences.
- Никакие данные диктовки не отправляются в сеть.

## Очистка

Историю можно очистить в `Настройки → История → Очистить историю…`. Операция
требует подтверждения и удаляет только JSON истории LocalFlow. Отключение
истории останавливает новые записи, но не удаляет существующие.

## Защищённые поля

LocalFlow отказывается диктовать в password/secure fields и при активном
Secure Event Input. Перед вставкой приложение повторно проверяет, что цель
ввода не изменилась.

## Разрешения macOS

- Microphone — получение речи во время записи.
- Accessibility — определение и изменение активного поля.
- Input Monitoring — наблюдение физической Right Option.
- Event Posting — контролируемый fallback для Command-V.
